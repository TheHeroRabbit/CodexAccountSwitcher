## 已知边界

- EXE 未使用商业代码签名证书，签名状态为 `NotSigned`；用户首次运行时可能看到 Windows 信誉提示。
- PyInstaller 警告仅包含当前 Windows/Tkinter 构建不使用的可选跨平台模块；其中 `fcntl` 是文件锁在非 Windows 分支的延迟导入，Windows 使用内置 `msvcrt`。警告已人工审查，未发现产品所需模块缺失。
- 为避免触碰或泄露真实凭据，验收未使用用户真实 `auth.json`、OpenAI 会话或 DeepSeek API Key；认证文件事务和故障路径由隔离临时目录中的虚构数据覆盖。
- 自动同步只管理官方 `auth_mode = "chatgpt"` 且能唯一识别账号的认证文件；API Key、旧格式、无法识别或身份冲突的文件仍按安全兼容策略处理。缺少可验证身份的旧 ChatGPT 记录可读取、添加和切换，但必须重新添加后才能安全更新。
- 跨进程锁是本工具实例之间的协作锁，不强制任意第三方程序遵守；Codex 会在写入前停止，且程序在判断、备份、替换验证和回滚前多次复检哈希。验收覆盖了各检查窗口内的外部变化，但不宣称独立锁文件提供文件系统级原子比较交换。
- GitHub Actions 文件已完成本地语法和等价命令验证，但托管流水线只能在推送到 GitHub 后实际运行。
