Codex 切换器 v1.4.0

- 切换前自动保存当前 ChatGPT 账号由 Codex 刷新后的最新认证，避免旧 auth.json 覆盖轮换后的令牌。
- Codex 刷新令牌后仍可按稳定账号身份识别“当前”账号；账号 ID 不写入清单、日志或界面。
- 阻止同一 ChatGPT 身份的重复账号记录，以及跨账号、跨认证模式的错误手动覆盖。
- 自动同步增加预期旧哈希比较、临时副本源哈希校验、备份后复检与跨进程事务锁；身份重复、错配、并发更新或副本在写入前后被修改时安全停止，不会用旧备份覆盖较新认证。
- 目标认证在切换或回滚前再次变化时会保留新登录并停止覆盖；同步已成功但后续失败时，界面会刷新并明确提示部分结果。
- 支持在 OpenAI 与 DeepSeek V4 Flash 之间安全切换。
- DeepSeek API Key 保存到 Windows 凭据管理器，界面仅显示末四位。
- 支持在 DeepSeek 模式下直接选择 OpenAI 账号并完成恢复、切换和重启。
- 保护原有 Codex 配置；保留 MCP、插件和项目设置等非受管字段。
- 检测配置冲突；写入失败时回滚配置、模型目录和认证文件。
- 保留账号添加、手动更新、备注、移除、切换与 Microsoft Store 客户端自动重启。
- 优化浅色界面、表格留白、按钮比例、对话框布局和程序图标。

说明：当前自动重启仅适用于 Microsoft Store 版 Codex；本程序为非官方本地辅助工具。
