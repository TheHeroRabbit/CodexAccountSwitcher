Codex 切换器 v1.5.0

- 在保留 DeepSeek V4 Flash（deepseek-v4-flash）的同时，正式开放 V4 Pro（deepseek-v4-pro）；DeepSeek 接入要求 Codex 0.144.0 或更高版本。
- DeepSeek 页面新增 Flash“速度优先”和 Pro“能力优先”选择器，分别显示所选模型与当前实际模型。
- 支持从 OpenAI 直接进入任一模型，也支持 V4 Flash 与 V4 Pro 双向直接切换并重启 Codex。
- 在 DeepSeek 模式下更新 API Key 时保持锁内重新确认的当前实际模型，不会意外应用尚未确认的另一模型选项。
- 受管的 V4 Flash 与 V4 Pro 统一使用 model_reasoning_effort = "max"；这是本程序策略，不是 DeepSeek 官方强制要求。
- 模型 slug 使用严格白名单；未知或不受支持的 DeepSeek 模型不会被猜测、接管或覆盖。
- CODEX_HOME 中新增 DPAPI 加密的全局 provider 事务日志；状态读取和切换会先恢复硬退出现场，完整提交会确认完成，部分提交会安全回滚，第三方第三态会失败关闭并保留现场。
- “账号文件”目录新增独立 DPAPI 加密事务日志，认证副本、账号清单和清单备份的导入、更新、移除、重命名与修复可在硬退出后确认提交或安全恢复；第三态外部内容不会被旧副本覆盖。
- 恢复状态、models.json 与 config.toml 增加预期旧内容比较、逐文件写后复检和安全回滚；操作期间出现较新外部内容时停止覆盖。共享锁只能协调本程序实例，普通文件 API 的最终 TOCTOU 边界仍按“不确定就不覆盖”处理。
- DeepSeek Windows 凭据改为按 CODEX_HOME 隔离；v1.4 全局凭据只由默认 home 验证复制并写迁移标记，旧目标为降级兼容保留且不会重复导入；自定义 home 仅从可信活动受管配置对账。
- 硬退出后，受管且无冲突的活动 DeepSeek config.toml 是实际 API Key 权威；OpenAI 模式保存值仍作为下次切换偏好。
- 全局事务日志绑定创建事务的 provider_state.dat 路径；不同便携副本不会跨数据目录自动恢复，需返回原始副本处理且不得手动删除日志/state。
- 同一 DeepSeek 会话内切换模型或更新密钥会保留最初的 OpenAI 恢复基线，并兼容 v1.4.0 已有的受管 Flash 状态。
- DeepSeek API Key 保存到 Windows 凭据管理器，界面仅显示末四位。
- 支持在 DeepSeek 模式下直接选择 OpenAI 账号并完成恢复、切换和重启。
- 保护原有 Codex 配置；保留 MCP、插件和项目设置等非受管字段。
- 发布 ZIP 统一使用 ASCII 文件名 CodexAccountSwitcher-v1.5.0.zip。
- 保留账号添加、手动更新、备注、移除、切换与 Microsoft Store 客户端自动重启。
- 账号存储、当前 auth.json、provider 配置、Windows 凭据和进程控制仍是独立恢复边界；若极端硬退出停在边界之间，下次打开会先收敛日志并按实际状态继续，不宣称跨资源的操作系统级原子事务。

说明：当前自动重启仅适用于 Microsoft Store 版 Codex；本程序不会联网验证 API Key，真实请求可能计费；本程序为非官方本地辅助工具。
